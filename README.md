## 🌸 About The Project

**Vikora — My Little Space** is a personal profile website designed with a modern aesthetic, smooth animations, gradient effects and a beautiful dark interface.

The website brings together a personal profile, Ukrainian identity and social media links in one simple and elegant experience.

It is built using Next.js, TypeScript and Tailwind CSS, with a focus on responsive design and visual details.

## ✨ Features

- **Modern Profile Section** — Circular profile photo with a rotating purple, blue and cyan gradient border.
- **Bilingual Content** — English and Ukrainian descriptions with animated gradient text.
- **Ukrainian Identity** — Ukrainian flag and Ukrainian-language content.
- **Social Media Integration** — Dedicated cards for YouTube, Snapchat, Telegram and Instagram.
- **Dark & Light Mode** — Switch between dark and light themes.
- **Animated Background** — Floating gradient orbs, sparkling stars and subtle visual effects.
- **Glassmorphism UI** — Transparent social cards with modern borders and blur effects.
- **Responsive Design** — Optimized for mobile phones, tablets and desktops.
- **Interactive Elements** — Hover animations and smooth transitions.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/GxAniket/vikora.git
```

### 2. Navigate to the Project

```bash
cd vikora
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Install Lucide React

```bash
npm install lucide-react
```

### 5. Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## ⚙️ Customization

You can customize the website by editing:

- **Profile Name:** `app/page.tsx`
- **Profile Image:** `public/images/vikora.png`
- **Social Media Links:** `socials` array in `app/page.tsx`
- **Colors and Animations:** `app/globals.css`
- **Website Metadata:** `app/layout.tsx`

To activate Instagram, add the actual Instagram profile URL to its social object in the `socials` array.

## 🌐 Deployment

This project can be deployed using [Vercel](https://vercel.com/), the platform created by the team behind Next.js.

General deployment steps:

1. Push your project to GitHub.
2. Import the repository into Vercel.
3. Configure the project settings.
4. Deploy the application.

Your website will then be available through your deployment URL.
